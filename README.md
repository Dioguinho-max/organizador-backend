🌐 **Acesse o sistema principal (Frontend):**  
https://organizador-frontend.vercel.app/

---

## 🚀 Sobre o Projeto

O **Organizador de Estudos — Backend** foi desenvolvido com foco em:

- 🔐 Segurança e autenticação JWT
- 📋 CRUD completo de tarefas
- 📊 Estatísticas de desempenho
- 🏆 Ranking global por média
- 🤖 Integração com Inteligência Artificial
- 📜 Histórico de uso da IA
- 🚦 Controle de limite diário de geração

A API é consumida pelo frontend hospedado na Vercel.

---

## 🛠️ Stack Tecnológica

- Node.js
- Express
- PostgreSQL
- bcrypt
- jsonwebtoken (JWT)
- Axios
- Hugging Face Inference API
- Modelo utilizado: `mistralai/Mistral-7B-Instruct-v0.2`
